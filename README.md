# Gym Tracker & Fueling Hub — Project Foundation

This commit creates a clean, scalable project foundation focused on modular architecture and separation of concerns.

Goals:
- Clean and maintainable code
- Separation of business logic from UI
- Modular architecture ready for long-term development
- Easy to convert into cross-platform apps later (React Native / shared TypeScript core)

What's included:
- TypeScript-based core domain models and module boundaries
- Lightweight repository & service ports (interfaces) for each module
- In-memory stub repositories to run and test logic without infrastructure
- Docs explaining architecture and design decisions

See docs/ARCHITECTURE.md for full rationale.
